# Swagger UI Orchis

Lihat [panduan menjalankan Swagger](../API.md).

- `index.html`: Swagger UI dengan spec lokal disematkan.
- `openapi.yaml` / `openapi.json`: spesifikasi OpenAPI 3.0.3.
- `openapi-spec.js`: salinan JSON untuk pemuatan langsung lewat `file://`.
- `guide.html` / `API-DOCUMENTATION.md`: panduan dan referensi source.
- `swagger-ui/`: Swagger UI 5.34.1 beserta lisensinya.
